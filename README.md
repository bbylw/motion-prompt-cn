## 我为什么做这个

我发了几条短视频，给动效运动和镜头运动加上了名字。接下来几天收到了很多评论。其中一条说，阻碍他们的不是缺乏想象力，而是不知道这种运动叫什么名字。

读到这条，我想：如果熟悉各自领域的人，用多种语言，把与 AI 良好协作所需的「共同语言」整理成可翻阅的库，会非常有用。于是我尝试把它做成了 GitHub 仓库。

这不是要照搬的一种风格。在这里，你可以使用提示词和说明，制作类似这样的动效，也可以为你的领域、你的语言制作同类名称示例，用你喜欢的任何观感。

另一位评论者说：「这就是成为创意总监的方式」。确实如此。如果世界各地有更多创意总监，与 AI 一起做出好作品，那将是很棒的事。

大瀧 昌平

## 三种使用方式

### 1. 打开名称库，挑选后发送给 AI

在 Claude Code 或 Codex 中安装 `motion-prompt` 技能后，只需提出请求即可打开本图库。你不需要记住名称或编号。不确定某物叫什么时，像查字典一样打开名称库。

```sh
npx skills add showheyohtaki/motion-prompt
```

1. 对 AI 说：
   ```text
   Open the motion-prompt library.
   ```
2. 图库在浏览器中打开。在想要的示例上按「Pick」，可多选。屏幕底部的备注栏可输入简短说明，如「用于开场标题」。
3. 按「Send to AI」，你的选择会发送给 AI。回到它并说明你想做什么：
   ```text
   Edit the opening of this video like this.
   ```

Agent 只使用你挑选的内容。它获取规格和参考代码，按你项目的方式构建到你的视频或网站中。说出类别即可，如「给我看镜头运动」，图库会按该领域的 Pack 打开（如有第一弹和第二弹则一起显示）。

对于没有技能的 AI，在图库中挑选，按屏幕底部的「Copy picks」，将文本粘贴到对话中。它包含示例和规格 URL。

**知道编号时**，可跳过图库直接按编号请求：

```text
Use the motion-prompt skill with #012 and #045 to make this product video look professional.
```

```text
Replace the part where the title appears with #005 from motion-prompt. Keep the length and the transitions before and after it.
```

```text
Turn the camera move in motion-prompt #032 into an English prompt for Veo. The subject is a coffee cup on a desk.
```

其他安装方式和 agent 的行为见下方[技能参考](#技能参考)。

### 2. 查一下名称，然后告诉你的 AI

打开[列表](https://github.com/showheyohtaki/motion-prompt/tree/main/packs)或图库，找到你想做的东西，在提示词中使用它的名称。再补充时长、强度和运动方式，结果会更接近你的设想。

```text
Bring the title in with a mask reveal from below, 0.6 s, each line slightly after the one before.
```

```text
Slow dolly in toward her face; move the camera, do not zoom.
```

这种方式无需安装。名称可用于编程 AI、视频生成模型或给人的简报。

### 3. 为你自己的领域或语言制作一个版本

[`make-your-own/`](https://github.com/showheyohtaki/motion-prompt/tree/main/make-your-own) 提供了可直接复制粘贴给编程 AI 的提示词、渲染视频的脚本，以及两个已完成示例（HTML 源文件、三段视频和一张速查表图片）。

| 目标 | 提示词 |
|---|---|
| 另一种语言的同款视频 | [`01-translate.md`](https://github.com/showheyohtaki/motion-prompt/blob/main/make-your-own/prompts/en/01-translate.md) |
| 你自己领域的名称，你自己喜欢的观感 | [`02-your-own-field.md`](https://github.com/showheyohtaki/motion-prompt/blob/main/make-your-own/prompts/en/02-your-own-field.md) |
| 单页速查表图片 | [`03-cheatsheet-image.md`](https://github.com/showheyohtaki/motion-prompt/blob/main/make-your-own/prompts/en/03-cheatsheet-image.md) |

领域不限于视频。灯光、声音、UI、摄影、烹饪、建筑：任何「知道名称才能提出需求」的领域都适用。

## 技能参考

需要 Node.js 18 或更高版本。

### 安装

**用提示词。** 粘贴到 Claude Code 或 Codex：

```text
Read https://github.com/showheyohtaki/motion-prompt and install the motion-prompt skill in this environment. When it is installed, tell me how to use it in three lines.
```

**用命令。** 使用 `skills` 安装器，适用于 Claude Code、Codex 和其他读取 Agent Skills 的 agent：

```sh
npx skills add showheyohtaki/motion-prompt
```

**作为 Claude Code 插件安装。**

```text
/plugin marketplace add showheyohtaki/motion-prompt
/plugin install motion-prompt@motion-prompt
```

**手动安装。** 将 `skills/motion-prompt` 文件夹复制到以下位置之一：

| 位置 | 范围 |
|---|---|
| `~/.claude/skills/` | Claude Code，所有项目 |
| `~/.agents/skills/` | Codex 等，所有项目 |
| 项目中的 `.claude/skills/` | Claude Code，仅该项目 |
| 项目中的 `.agents/skills/` | Codex 等，仅该项目 |

### 给 Agent 的安装步骤

本节供收到上文「用提示词」那段指令的 AI agent 使用。

1. 用 `node --version` 确认 Node.js 18 或更高版本可用。
2. 在用户的项目目录执行下面的命令。若询问要安装给哪个 agent，选择你自己的那个。
   ```sh
   npx skills add showheyohtaki/motion-prompt -y
   ```
3. 若第 2 步无法执行，则拉取仓库并复制目录。Claude Code 复制到 `.claude/skills/`，其他 agent 复制到 `.agents/skills/`（或对全部项目使用 `~/.claude/skills/`、`~/.agents/skills/`）。
   ```sh
   git clone --depth 1 https://github.com/showheyohtaki/motion-prompt.git /tmp/motion-prompt
   mkdir -p .claude/skills
   cp -R /tmp/motion-prompt/skills/motion-prompt .claude/skills/
   ```
4. 确认安装结果。把 `<skill-dir>` 换成技能实际安装的位置（含 `SKILL.md` 的目录）。能打印出数据来源和元素数量即表示成功。
   ```sh
   node <skill-dir>/scripts/motion-prompt.mjs info
   ```
   退出码 3 表示无法访问数据源，取得网络权限后重试。
5. 阅读 `<skill-dir>/SKILL.md`，用三行告诉用户怎么使用。例如：
   - 说「打开 motion-prompt 名称库」，图库即会打开；在想要的示例上按「Pick」，再按「Send to AI」。
   - 然后说明想做什么，例如「按这样编辑这个视频的开场」。
   - 知道编号时也可以直接请求：「使用 #012 和 #045」。

不要改动已有的设置文件或其他技能。

### Agent 的行为

- 当你请求名称库时，它会在浏览器中打开图库并等待（最多 15 分钟），直到你挑选并按下「Send to AI」。
- 它会判断你的项目如何生成视频：Canvas、Remotion、CSS、After Effects 或视频生成模型提示词。
- 它只使用你挑选的内容或你给出的编号，不使用其他。当你未选择时，它会建议打开图库；如果你让它选择，它会为每个场景搜索目录。
- 它在你的项目中重建这些运动。时间、缓动和幅度保持发布时的设定，而文字、颜色和图像变成你的。
- 回复末尾会列出它使用的编号、每个编号进入的场景、它改了什么，以及每个示例的链接。

### 工作原理

- 一个元素就是一个函数 `cells[i](ctx, w, h, u)`。`ctx` 是 Canvas 2D 上下文，`w` 和 `h` 是卡片尺寸，`u` 是周期内的时间（秒）。
- 画面只取决于 `u`。绘制时函数不读取时钟、不使用随机数，因此实时播放和逐帧渲染得到相同帧。
- 颜色、尺寸、周期长度和共享辅助函数收集在每个 Pack 的「kit」中。元素需要其 Pack 的 kit。
- 无外部依赖库。

技能由三个文件组成：指令（`SKILL.md`）、将元素移植到各类视频项目的说明（`references/porting.md`）、查找元素的 Node 脚本（`scripts/motion-prompt.mjs`，仅标准库）。

| 命令 | 作用 |
|---|---|
| `pick` / `pick --pack camera` | 打开图库，打印「Send to AI」发送的内容：编号、名称、规格和备注。等待最多 15 分钟 |
| `search typewriter text` / `search 文字 登場` | 按场景查找元素（英文或日文词） |
| `list` / `list --pack motion` | 所有 Pack 概览，或逐个列出某 Pack |
| `get 12 #045` | 打印这些编号的规格和代码（一次最多 8 个） |
| `kit motion` | 某 Pack 的共享代码 |
| `prompt 12` | 某元素的可复制提示词 |
| `info` | 显示数据来源、数量及缓存位置 |

脚本只对以下文本文件发起 GET 请求，不上传你项目的任何内容。`pick` 还会在本机（127.0.0.1）打开临时监听，只接收图库中「Send to AI」发送的编号和备注。

1. `https://showheyohtaki.github.io/motion-prompt/api/v1/`
2. 若无法访问：`https://raw.githubusercontent.com/showheyohtaki/motion-prompt/main/api/v1/`

| 文件 | 内容 |
|---|---|
| `catalog.json` | 版本、数量、Pack，以及每个元素的名称、含义、摘要、规格和标签 |
| `{ja,en}/catalog.tsv` | 制表符分隔的索引（id、pack、category、title、tags、summary） |
| `{ja,en}/e/{id}.txt` | 单个元素：署名行、展示内容、规格、代码 |
| `{ja,en}/p/{id}.txt` | 单个元素的可复制提示词 |
| `kit/{pack}.js` | 某 Pack 的共享代码 |

如果克隆整个仓库，CLI 会先读取本地 `api/v1`，无需网络。下载的数据保留在磁盘上，当来源无法访问时使用保存的副本。

| 变量 | 默认值 |
|---|---|
| `MOTION_PROMPT_BASE` | 改从这里读取：本地文件夹或 URL，多个用逗号分隔 |
| `MOTION_PROMPT_CACHE` | 下载保存位置；`~/.cache/motion-prompt`，或主目录只读时用系统临时目录 |
| `MOTION_PROMPT_TTL` | 已保存 catalog 的信任时长（秒）；`21600`（6 小时） |

### 自己运行图库

```sh
git clone https://github.com/showheyohtaki/motion-prompt.git
cd motion-prompt
python3 -m http.server 8000
```

打开 `http://localhost:8000/` 查看图库（`index.html`）。在克隆中，`node skills/motion-prompt/scripts/motion-prompt.mjs pick --local` 会打开本地图库供挑选。文件格式见 [FORMAT.md](https://github.com/showheyohtaki/motion-prompt/blob/main/FORMAT.md)。
